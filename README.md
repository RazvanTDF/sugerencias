# Fortaleza 1786 — Sugerencias

Pagină pentru creat și imprimat foaia de sugerențe (A4) a restaurantului Fortaleza 1786, Oiartzun.

## Cum o folosești
- Deschizi `index.html` (sau link-ul de GitHub Pages) în Chrome.
- Scrii felul și prețul; clic pe **€** schimbă în €/kg, €/ud sau €/ración.
- **+** adaugă feluri, **×** le șterge; rândurile goale rămân libere la print.
- Butonul **Clásico / Pergamino** schimbă stilul foii.
- **IMPRIMIR** → A4, fără margini.

Datele se salvează automat în browser (pe fiecare calculator separat).
