# Fortaleza 1786 — Sugerencias

Pagină pentru creat și imprimat foaia de sugerențe (A4) a restaurantului Fortaleza 1786, Oiartzun.

## Cum o folosești
- Deschizi link-ul de GitHub Pages în Chrome.
- Scrii felul și prețul; clic pe **€** schimbă în €/kg, €/ud sau €/ración.
- **+** adaugă feluri, **×** le șterge; rândurile goale rămân libere la print.
- Butonul **Clásico / Pergamino** schimbă stilul foii.
- **IMPRIMIR** → A4, fără margini.

## Salvare pe GitHub
Datele se salvează în `datos.json` pe ramura `datos` (nu pe `main`, ca să nu se reconstruiască site-ul la fiecare modificare).
Oricine deschide pagina vede ultima versiune; pentru a **salva** e nevoie, o singură dată pe fiecare calculator,
de un token fine-grained (doar repo-ul `sugerencias`, permisiune *Contents: Read and write*),
pus prin butonul **🔑 Conectar GitHub**.
